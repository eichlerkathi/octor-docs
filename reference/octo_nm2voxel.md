# Convert octo coordinates between nm and Spelunker voxels

Convert octo coordinates between nm and Spelunker voxels

## Usage

``` r
octo_nm2voxel(xyz, res = getOption("octor.voxel_size"))

octo_voxel2nm(xyz, res = getOption("octor.voxel_size"))
```

## Arguments

- xyz:

  n x 3 matrix / data.frame

- res:

  voxel size in nm
