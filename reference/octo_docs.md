# Open the octor documentation website

Opens the online documentation (function reference and guides) in your
browser, optionally at the page of one function.

## Usage

``` r
octo_docs(topic = NULL)
```

## Arguments

- topic:

  optional function name, e.g. `"octo_read_meshes"`

## Value

invisibly, the URL

## Examples

``` r
if (FALSE) { # \dontrun{
octo_docs()
octo_docs("octo_update_ids")
} # }
```
